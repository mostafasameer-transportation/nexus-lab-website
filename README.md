# Nexus Lab Website

A modern, responsive website for Nexus Lab, designed to showcase the lab's research, team, publications, honors, and contact information.

## Website

The website is built as a single-page HTML website using:

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Responsive design
- CSS animations and transitions

## Features

- Responsive navigation
- Hero section with animated graphics
- Research areas
- Team and principal investigator sections
- Publications
- Honors and achievements
- Contact section
- Responsive layout for mobile and desktop
- Smooth scrolling and visual animations
